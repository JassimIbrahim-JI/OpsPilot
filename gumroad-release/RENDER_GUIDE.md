# 🚀 Render — دليل النشر خطوة بخطوة (بالصور النصية)

> انشر TaskFlow Pro مجانًا على Render في 5 دقائق.

---

## الخطوة 1: سجّل الدخول

اذهب إلى **https://render.com** واضغط **"Get Started"** ثم سجّل بحساب **GitHub**.

```
┌─────────────────────────────────────────┐
│            render.com                   │
│                                         │
│   [ Get Started ]  [ Sign In ]          │
│                                         │
│   ┌───────────────────────────────┐     │
│   │  Continue with GitHub  ← اضغط  │     │
│   └───────────────────────────────┘     │
└─────────────────────────────────────────┘
```

---

## الخطوة 2: إنشاء خدمة جديدة

بعد تسجيل الدخول، اضغط الزر الأزرق **"New +"** ثم اختر **"Static Site"** (لأن TaskFlow Pro موقع ثابت).

```
┌─────────────────────────────────────────┐
│  Dashboard                              │
│                                         │
│  [ New + ]  ← اضغط هنا                  │
│     ├── Web Service                     │
│     ├── Static Site  ← اختر هذا         │
│     ├── Background Worker               │
│     └── ...                             │
└─────────────────────────────────────────┘
```

---

## الخطوة 3: اختر الريبو

اختر **`JassimIbrahim-JI/TaskFlowAI`** من القائمة.

```
┌─────────────────────────────────────────┐
│  Connect a repository                   │
│                                         │
│  🔍 [ Search repositories... ]          │
│                                         │
│  ☑ JassimIbrahim-JI/TaskFlowAI  ← اختر  │
│                                         │
│  [ Connect ]                            │
└─────────────────────────────────────────┘
```

---

## الخطوة 4: الإعدادات (املأ الحقول)

| الحقل | القيمة |
|---|---|
| **Name** | `taskflow-pro` |
| **Branch** | `main` |
| **Build Command** | `npm install && npm run build` |
| **Publish Directory** | `dist` |

```
┌─────────────────────────────────────────┐
│  Name:        [ taskflow-pro ]          │
│  Branch:      [ main ]                  │
│  Build Cmd:   [ npm install && npm run build ] │
│  Publish Dir: [ dist ]                  │
│                                         │
│  [ Create Static Site ]  ← اضغط         │
└─────────────────────────────────────────┘
```

> 💡 **ملاحظة:** لأن مشروعك فيه `render.yaml`، قد يكتشف Render هذه القيم تلقائيًا. إذا ظهرت معبأة مسبقًا، فقط اضغط "Create".

---

## الخطوة 5: انتظر النشر

سيبدأ Render في البناء (2-4 دقائق). سترى سجل البناء:

```
┌─────────────────────────────────────────┐
│  Deploying taskflow-pro...              │
│                                         │
│  ✓ Cloning repository                   │
│  ✓ Installing dependencies (npm install)│
│  ✓ Building (npm run build)             │
│  ✓ Uploading dist/                      │
│                                         │
│  🎉 Your site is live!                  │
└─────────────────────────────────────────┘
```

---

## الخطوة 6: احصل على الرابط

بعد اكتمال النشر، ستجد الرابط في أعلى الصفحة:

```
https://taskflow-pro-xxxx.onrender.com
```

**افتحه** — سترى واجهة TaskFlow Pro الفاخرة! 🎉
