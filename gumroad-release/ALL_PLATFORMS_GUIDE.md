## 1️⃣ Render — معاينة حية مجانية (5 دقائق)

**الهدف:** رابط حي يعرض منتجك للمشترين.

1. اذهب إلى https://render.com → **"Get Started"** → سجّل بحساب GitHub
2. اضغط **"New +"** → **"Static Site"**
3. اختر repo **`JassimIbrahim-JI/TaskFlowAI`**
4. املأ:
   - Build Command: `npm install && npm run build`
   - Publish Directory: `dist`
5. اضغط **"Create Static Site"**
6. انتظر 2-4 دقائق → ستحصل على رابط `https://taskflow-pro-xxxx.onrender.com`

✅ **النتيجة:** رابط معاينة حي تشاركه في كل إعلاناتك.

5. **السعر:** Regular `$29` / Extended `$145`
